# Security Policy

## Supported state

This repository is an evidence-oriented portfolio project with a locally verified release candidate. It has no declared production deployment or long-term support branch.

## Reporting

Report a suspected vulnerability privately to the repository owner through a private GitHub security advisory when available. Include:

- affected revision;
- reproducible steps using synthetic data;
- expected and observed behavior;
- impact and preconditions; and
- whether credentials or personal data may have been exposed.

Do not publish secrets, real incident data, or an uncoordinated exploit in a public issue.

## Response boundary

No response-time commitment is promised. The owner should acknowledge, reproduce, classify, patch, and add regression evidence before public disclosure when feasible.
