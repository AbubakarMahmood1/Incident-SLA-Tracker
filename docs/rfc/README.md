# Requests for Comments

RFCs describe material proposals that are **not part of the current implementation**. A draft may be rejected without changing version-1 claims. Accepted RFCs still require implementation, tests, migration evidence, and an ADR when they alter architecture.

| [0003](0003-provider-delivery-receipts.md) | Draft | Provider receipts, webhooks, and stronger delivery deduplication |
| [0004](0004-collaboration-modules.md) | Draft | Comments, attachments, and external collaboration integration |
