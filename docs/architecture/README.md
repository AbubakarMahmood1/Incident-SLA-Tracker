# C4 Architecture Views

These Mermaid diagrams are editable architecture sources. They describe the bounded version-1 system rather than an imagined enterprise deployment.

1. [System context](01-context.md)
2. [Containers](02-containers.md)
3. [Components](03-components.md)
4. [Deployment](04-deployment.md)

The container view is the primary high-level architecture. The component view exists because the command, domain, evaluator, ledger, and delivery boundaries are material to the project thesis. The deployment view separates software structure from the supplied Compose topology.

The diagrams require rendering and visual inspection before the documentation gate is complete.
